# Football Club Website

This is a modern football club website built with React, Vite, and TypeScript.

## Features

- Responsive design
- Modern UI components
- Team management
- Player profiles
- Match schedules
- News section
- Contact information

## Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- Radix UI
- React Router
- React Query

## Getting Started

1. Clone the repository
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```

## Deployment

The site is deployed on GitHub Pages at: https://pomidorkaeg.github.io/pls

To deploy locally:
```bash
npm run deploy
```
